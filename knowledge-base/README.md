# База знаний (Obsidian)

Это Obsidian-vault проекта. Сюда записываются темы, которые были непонятны и которые
пришлось изучить: новый язык/фреймворк, библиотека, технология, концепция. Заметки
связываются между собой ссылками `[[...]]`, чтобы получалась система знаний, а не набор
разрозненных фактов.

> Принцип курса: информацию найти легко (нейросети), сложнее — **успеть понять**.
> Поэтому фиксируем понятое здесь.

## Как пользоваться
- Открыть папку `knowledge-base/` как vault в Obsidian.
- Концепции — в `concepts/`, проектные решения (ADR) — в `decisions/`.
